# Mémoire de Master – Mathématiques  
**Année académique 2023-2025**  
**En collaboration avec Cenaero**

## 📘 Description
Ce dépôt contient les scripts développés dans le cadre de mon mémoire de master en mathématiques appliquées, réalisé en partenariat avec Cenaero.  
**Attention** : les jeux de données utilisés sont trop volumineux pour être hébergés sur GitHub.  
Par conséquent, les scripts présents ici ne sont **pas directement exécutables** sans ces données. Ils sont fournis à titre **informatif et illustratif**.

## 🗂 Organisation des fichiers

| Fichier                    | Contenu                                                                                          |
|----------------------------|--------------------------------------------------------------------------------------------------|
| `Etat_de_l_art.py`         | Scripts liés au **chapitre 1 – État de l’art**.                                                  |
| `JddSimples.py`            | Expérimentations du **chapitre 3 – Études sur deux jeux de données simples**.                   |
| `Méca_Struct.py`           | Étude de cas du **chapitre 4** (partie **sans groupement** de variables).                       |
| `Groupement.py`            | Étude de cas du **chapitre 4** (partie **avec groupement** de variables).                       |
| `Opti.py`                  | Scripts utilisés pour le **chapitre 5 – Optimisation**, en lien avec la plateforme Minamo.       |
| `CreationXls.py`           | Génération de fichiers Excel pour faciliter les échanges avec Minamo (chapitre 5).              |
| `cas_test_diabetes.py`     | Implémentation orientée objet du **cas test Diabète** : chaque cas est représenté comme un objet. |
| `cas_test_mécanique.py`    | Implémentation orientée objet du **cas test Mécanique**.                                         |
| `cas_test_structuraux.py`  | Implémentation orientée objet du **cas test Structuraux**.                                       |

Les fichiers `cas_test_*.py` utilisent la **programmation orientée objet** : chaque cas test est modélisé sous forme de classe, ce qui permet de mieux structurer les données, les paramètres et les méthodes associées à chaque étude.

## 📌 Remarques

- Les jeux de données proviennent de contextes industriels (simulation mécanique) et ne sont pas publics.
- Le code a été organisé par chapitre pour refléter la structure du mémoire.
- Si vous souhaitez exécuter une partie du code, vous pouvez me contacter pour une version adaptée avec des jeux de données plus légers à des fins de démonstration.
